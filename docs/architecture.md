# Architecture

The repository is a client-side Create React App project written in TypeScript.

- `src/index.tsx` boots the React application.
- `src/App.tsx` composes the course heading, React logo, and navigation component.
- `src/components/NavBar.tsx` uses React Bootstrap for the sample navigation UI.
- `public/` contains the static browser entry assets.

There is no backend service, database, external integration, or committed hosting configuration in this repository.
