# Scope and roadmap

## In scope

- A browser-based React exercise.
- A sample navigation component and course-oriented screen content.
- Local development, test, and production-build commands supplied by Create React App.

## Out of scope

- Backend APIs, authentication, data persistence, and production operations.
- Curriculum expansion, dependency upgrades, routing redesign, and deployment setup.

## Roadmap

No committed delivery roadmap exists. Any modernization or feature work must be planned as a separate, approved learning objective.
